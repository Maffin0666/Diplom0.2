# Лектория.Ai

Клиент-серверный прототип ВКР: фотография конспекта поступает с телефона на ноутбук, сервер распознаёт русский текст и формулы, готовит речь и MP3 с временными метками, а мобильный клиент позволяет слушать и переходить между фрагментами.

## Состав проекта

| Каталог | Назначение |
| --- | --- |
| `server/` | FastAPI, OCR, подготовка речи, Silero TTS, очередь заданий и SQLite |
| `client/app/` | Flutter-приложение для Android и iOS |
| `client/api/openapi.v1.json` | Сохранённый контракт API |
| `scripts/` | Подготовка моделей, проверка API и оценка OCR |
| `tests/` | Быстрые серверные тесты без загрузки больших моделей |

Сервер рассчитан на ноутбук с CPU и 16 ГБ ОЗУ. Тяжёлые задания обрабатывает один работник; по умолчанию ещё два задания могут ждать в очереди. Статусы и результаты сохраняются в SQLite. Модели работают локально после первоначальной загрузки.

## Запуск и проверка

1. Установите Python 3.12 и FFmpeg. Выполните шаги из [инструкции сервера](SERVER_SETUP.md); крупные OCR-веса загружаются отдельно. Файл Silero уже присутствует в исходной истории проекта.
2. Запустите `python run.py` и проверьте `http://127.0.0.1:8000/health` на ноутбуке.
3. Соберите клиент по [инструкции Flutter](client/app/README.md). В его настройках укажите IP ноутбука в той же Wi-Fi-сети.
4. Для проверки полного HTTP-маршрута используйте `python -m scripts.smoke_client_api --image test_lecture.jpg`.

Быстрые серверные проверки: `python -m unittest discover -s tests -v`. Проверки клиента из `client/app`: `flutter analyze`, `flutter test`, `flutter build apk --debug`.

## Данные и ограничения

Локальные фотографии `img_for_test/`, эталонные расшифровки `tests/fixtures/handwriting_ground_truth.json`, сырые результаты `reports/`, новые OCR-модели, база SQLite, журналы и новое готовое аудио исключены из Git. Отчёты о ходе разработки и локальный журнал изменений также не публикуются. Для личной оценки OCR можно передать свои фотографии и JSON в `scripts.benchmark_handwriting` через `--images-dir` и `--references`.

MVP демонстрирует полный цикл на печатных материалах и части почерков. Сложная рукопись всё ещё распознаётся с существенными ошибками; отдельного распознавания двумерных рукописных формул нет. Android debug-сборка использует HTTP в доверенной локальной сети. Для публичного развёртывания нужны HTTPS, аутентификация и отдельная подпись release-сборки.
