# Мобильный клиент «Лектория.Ai»

Flutter-приложение для Android/iOS: снимок конспекта → распознавание на сервере → локальная запись MP3 → воспроизведение по фрагментам. Реализованы крупные элементы, системный масштаб текста, дополнительная настройка 100–200%, светлая/тёмная темы, метки для экранного диктора и команды по нажатию кнопки микрофона.

При первом запуске открывается приветствие. На главном экране доступны недавние лекции, создание снимка, библиотека и настройки. В библиотеке работают поиск и фильтры по типу содержимого; меню карточки позволяет открыть лекцию, скопировать текст и удалить локальную запись после подтверждения. Экран обработки показывает фактический статус задачи без выдуманного процента. В плеере есть крупный текущий фрагмент, переходы между фрагментами, скорости 0,75–2× и сохраняемая закладка. Полный текст и исходный снимок раскрываются по нажатию. В настройках можно выбрать светлую, тёмную или системную тему. Дополнительный масштаб применяется поверх системного, суммарно до 250%.

Оформление следует палитре «Лектория.Ai»; маскот нарисован вектором и анимируется только там, где это полезно. При системном ограничении анимации он статичен. Для текста пока используется системный шрифт платформы: файл Golos Text не входит в проект.

Экран подготовки к съёмке показывает рамку и советы, затем открывает системную камеру. Он пока не измеряет резкость и освещённость в реальном времени. Сервер передаёт общий статус задачи, поэтому клиент не показывает отдельный прогресс предобработки, распознавания, вербализации и синтеза. Экспорт DAISY пока отсутствует; доступно копирование распознанного текста.

## Первый запуск

Flutter SDK установлен. Платформенные каталоги `android` и `ios` уже созданы. Из `client/app` в обычной командной строке Windows (`cmd`) выполните:

```bat
tool\configure_platforms.cmd
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
flutter devices
```

Если используете PowerShell, запускайте скрипт командой `.\tool\configure_platforms.ps1`. Команду `flutter create --platforms android,ios --project-name lecture_reader .` повторять не нужно: она уже выполнена. Скрипт добавляет разрешения в созданные Android/iOS-проекты. Локальный HTTP разрешён лишь для **отладочной сборки Android**. Для релизной сборки понадобится HTTPS. iOS-сборка требует macOS и Xcode.

`flutter run` запустится после подключения телефона Android с разрешённой отладкой по USB либо запуска эмулятора. Проверьте `flutter doctor -v` и `flutter devices`; затем выполните `flutter run -d <ID-устройства>`. Windows, Chrome и Edge, показанные Flutter, не поддерживаются текущим проектом, потому что он создан только для Android/iOS. [Официальная инструкция по подключению Android-устройства](https://docs.flutter.dev/platform-integration/android/setup#set-up-an-android-device).

На этом ноутбуке `flutter analyze` и `flutter test` проходят, debug APK успешно собран в `build/app/outputs/flutter-apk/app-debug.apk`. Android SDK, NDK 28.2.13676358 и CMake установлены. Базовый цикл камеры, отправки фото, получения результата и воспроизведения пользователь проверил на Galaxy A22. Обновлённый интерфейс нужно повторно проверить на телефоне, в том числе с TalkBack и крупным системным шрифтом.

Если первая сборка остановится на скачивании Maven-зависимостей, повторите команду после восстановления сети. При повторяющихся TLS-обрывах в `cmd` можно временно включить IPv4 для Java и уменьшить число параллельных задач:

```bat
set JAVA_TOOL_OPTIONS=-Djava.net.preferIPv4Stack=true
set GRADLE_OPTS=-Dorg.gradle.workers.max=2 -Dorg.gradle.daemon=false
flutter build apk --debug
```

Эти `set` действуют только в текущем окне командной строки. На этой машине после установки NDK и докачки Gradle-зависимостей APK собрался с такими параметрами.

Запустите сервер на ноутбуке так, чтобы он слушал адрес локальной сети. В приложении откройте «Настройки», укажите `http://IP-НОУТБУКА:8000` и нажмите «Проверить связь». `localhost` на телефоне означает сам телефон. После проверки снимите или выберите фото. JPEG, PNG и WEBP поддерживаются; изображение уменьшается до 3000 пикселей по стороне.

Клиент сохраняет исходный снимок и UUID перед загрузкой. Если ответ потерян, повторное открытие лекции сначала ищет задачу по UUID; при HTTP 404 отправляет тот же снимок с тем же UUID. Очередь 429 повторяется с паузой. Результат и MP3 сохраняются в личных документах приложения. После сохранения лекцию можно слушать без сервера. Голосовые команды: «воспроизвести», «пауза», «следующий», «предыдущий», «повтори формулу». Микрофон включается кнопкой; работа распознавания речи зависит от настроек и языка на устройстве.

Если на Galaxy A22 при нажатии микрофона появляется сообщение о недоступной службе речи, проверьте, что на телефоне включена служба голосового ввода, выбран русский язык распознавания и разрешён микрофон для «Лектория.Ai» и самой службы. Плагин теперь пробует альтернативный поиск службы на Android. Если службы нет или она выключена, кнопки плеера и перехода между фрагментами остаются доступны. Подробности есть в [документации speech_to_text](https://pub.dev/packages/speech_to_text#not-working-on-a-particular-android-device).

Текущий APK собран в режиме `debug`: Android помечает его как отладочный, а доступ к серверу в локальной сети идёт по HTTP. Манифест приложения запрашивает доступ к микрофону и сети; сервис специальных возможностей не объявлен. Ради этого приложения не нужно включать «специальные возможности для неизвестных приложений». Снимки и аудио исключены из облачного резервного копирования Android.

Для распространения потребуется отдельный ключ подписи release-сборки и защищённое HTTPS-подключение к серверу. Шаблонная подпись release отладочным ключом удалена; `flutter build apk --release` пока не предназначен для установки пользователям.

Протокол сервера: [OpenAPI](../api/openapi.v1.json). На Android обязательно проверьте экран с TalkBack и системным крупным шрифтом на физическом устройстве.
